# 05 Reflektion

## Labb 0: Första reflektion

Besvara frågorna:

1. Vad verkar labben handla om?

det verkar handla om hur säkerhet byggs in i itvecklings processed och inte bara i slutet.

2. Vilka risker kan finnas även i en enkel applikation?

Det kan använda icke verifierade dependencies. Ha hårdkodade lösenord/ information och kanske även om hur mycket tillgång man kan få till systemet

3. Vilka delar av CIA-triaden kan påverkas?

Alla kan påverkas
Konfidalitet - om det finns tillgång till info

Integritet - om informationen kan ändras

Tillgänglighet - om infon blir otillgänglig till användaren

4. Vad tror du en IT- och cybersäkerhetstekniker behöver tänka på i ett DevSecOps-flöde?

Det kräver mycket tänkandet genom hela utvecklings processen. Dokumentera säkerhetsproblem och köra regelbundna säkerhetskontroller.
