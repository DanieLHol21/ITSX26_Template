# CIA Analys

## Angriparen fick tillgång till info om anställda och har sedan uttget sig för att vara HR-personal för att få anställda att lämna ut känsliga information

### Konfidentalitet 
hotet påverkar konfidentalitet genom att anställda lämnar känslig info till angriparen. exempel på känslig info kan vara personupgifter, lönupgifter eller annan info bara den personen/HR- systemet borde kunna veta
***
### integritet
Integritet kan påverkas om angripare skulle lyckas att få den asntällda att ändra informationet i systemet eller utföra en åtgärd som inte är godkänd
***
### tillgänglightet
Tillgänglighet kan påverkas om angriparen lyckades och då kan orsaka problem i systemet genom att ändra/ ta bort viktig information
